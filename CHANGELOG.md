## [1.0.0] - 2026-11-18
- Owner and scope isolated skill catalogue with integer or UUID owners and UUID identifiers
- Raw-file drafts over HTTP (JSON with base64 for binary files, or multipart uploads) with bounded paths, file counts and sizes
- Revision-checked draft edits and publication, with stale revisions rejected
- Immutable published versions validated through the portable skillpack core, with content hashes verified on use
- Separate, revocable version availability; deleted skills deny access to every version
- `HasSkills` trait pinning exact versions to any model, enforcing owner, scope, availability and a configurable binding authorizer
- `ManagedSkillSource` and `SkillVersionResolver` for scoped, availability-checked consumption
- Imports from configured local roots and allowed hosts through extensible source providers, disabled by default
- Fail-closed authorization: the permissive owner-access default is refused until the host binds a real authorizer
- Configurable models, tables, requests, resources, response formatter, controllers, routes and write middleware
- Domain events dispatched after commit
